# AI Product Brief Builder

一个浏览器内运行的小工具，帮助产品经理在 5 分钟内将 AI 产品想法整理为结构化 brief：用户、任务、AI 价值、风险、MVP 范围和验证指标。

## Why

许多 AI 点子从“能不能接入模型”开始，导致目标用户、失败场景和验证方式迟迟没有被说清。这个工具将讨论顺序固定下来，先让问题和约束变得可见。

## How to use

直接在浏览器打开 `index.html`，填写几个关键字段，点击“生成产品简报”。你可以复制 Markdown，带到文档或团队讨论中继续完善。

## Product choices

- **No API required**：原型使用规则化模板，在本地生成内容，便于快速演示。
- **Assumptions first**：输出把未验证假设与风险单独列出，避免把想法包装成结论。
- **Small experiment**：默认给出一轮可在两周内完成的验证建议。

## Limitations

这不是自动生成完整 PRD 的 AI agent，也不会替代用户访谈或数据分析。它的价值是帮助团队更快形成一个可挑战、可验证的起点。
